# 🏥 Hospital Emergency Room Data Analysis Dashboard

## 📌 Project Overview

This project presents an interactive Hospital Emergency Room Dashboard designed to analyze patient activity and operational performance.

The dashboard provides insights into patient volume, average waiting time, patient satisfaction, admission status, demographic distribution, attendance status, and department referrals.

The objective of the project is to transform hospital emergency room data into meaningful insights that can help understand patient flow and identify areas for operational improvement.

## 🎯 Project Objectives

The dashboard was created to analyze:

- Total number of patients visiting the emergency room
- Average patient waiting time
- Patient satisfaction scores
- Patient admission status
- Patient attendance status
- Gender distribution
- Patient distribution across age groups
- Department referral patterns
- Monthly and yearly patient trends

---

## 🔍 Key Insights

Some observations from the dashboard include:

- A total of **485 patients** were recorded for the selected period.
- The average patient waiting time was approximately **35.51 minutes**.
- The average patient satisfaction score was **4.71**.
- Around **51.55% of patients were not admitted**, while **48.45% were admitted**.
- The patient gender distribution was almost evenly split.
- The **70–79 age group** recorded the highest number of patients among the displayed age categories.
- A large number of patients did not require department referral, while General Practice and Orthopedics received comparatively higher referrals.
- The dashboard allows analysis by **month and year**.
